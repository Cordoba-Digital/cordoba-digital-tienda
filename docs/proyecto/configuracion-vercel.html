Configuración de Vercel y variables de entorno

Cómo registrar credenciales sin filtrarlas ni guardarlas en Git.

Variables de entorno

  1. Entrar a Vercel → proyecto `cordoba-digital` → Settings → Environment Variables.
  2. Agregar cada variable para Production, Preview y Development según corresponda.
  3. No subir `.env` al repositorio.
  4. Después de guardar, volver a desplegar.

Variables esperadas

VariablePara qué
`DATABASE_URL`Conexión a Postgres (Neon/Vercel Postgres)
`APP_URL`URL pública del sitio, ej. `https://cordoba-digital.vercel.app`
`MP_ACCESS_TOKEN`Mercado Pago, si se activa
`MP_PUBLIC_KEY`Mercado Pago, si se activa
`MP_WEBHOOK_SECRET`Firma de webhooks de MP
`GOOGLE_PLACES_API_KEY`Comentarios/estrellas de Google Places
`GOOGLE_PLACE_ID`Negocio a consultar en Places

Región de funciones

Se dejó configurado para que las funciones corran en la misma región que Neon:

vercel.json
{ "$schema": "https://openapi.vercel.sh/vercel.json", "regions": ["cle1"] }

`cle1` equivale a AWS `us-east-2`.

Checklist

  • Commit y push de `vercel.json`
  • Deploy producción completado
  • Región runtime verificada como `cle1`
  • Variables de entorno cargadas en el panel
  • Secrets no versionados en Git
