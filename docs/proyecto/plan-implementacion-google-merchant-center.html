Plan de implementación: feed Google Merchant Center

Objetivo: Exponer un feed público compatible con Google Merchant Center directamente desde la nueva web y desde Neon.

Fase 1 — Preparar esquema de productos

Validar que Neon tenga o derive:

  • id
  • title
  • description
  • link
  • image_link
  • availability
  • price
  • currency
  • brand
  • condition
  • google_product_category
  • category
  • stock
  • gtin, mpn, sku cuando existan

Si faltan GTIN/MPN, Google puede aceptar productos corrientes, pero la calidad del feed baja.

Fase 2 — Crear el feed en Next.js

Crear una ruta:

/products.xml

con Content-Type:

application/xml; charset=utf-8

Debe devolver un <rss>/Atom o feed XML válido para Merchant Center.

Fase 3 — Mapear Neon al feed

Cada producto debe transformarse en un item con campos como:

id
title
description
link
image_link
availability
price [value][currency]
brand
condition: new

La disponibilidad puede salir de:

stock > 0 ? "in stock" : "out of stock"

Fase 4 — Validación

Agregar checks mientras lo hacemos:

  • URL pública sin bloqueo;
  • XML bien formado;
  • field id obligatorio;
  • imagen accesible;
  • precio con importe decimal;
  • link canónico;
  • máximo permitido por Google;
  • no devolver HTML ni error 500.

Fase 5 — Registrar en Google Merchant Center

En Merchant Center:

  1. Ir a Productos > Fuentes de datos.
  2. Agregar Feed.
  3. Elegir formato XML/RSS o CSV.
  4. Apuntar a:
https://cordoba-digital.vercel.app/products.xml
  1. Programar una frecuency recurrente.

Fase 6 — Verificar dominio

Separar en dos tareas:

  1. Verificar dominio de Merchant Center.
  2. Conectar Google Search Console si todavía no está vinculado.

Sin dominio verificado no queda completo el ciclo.

Fase 7 — Dejar automático

1. Endpoint + fetch de Google
Google llama cada 6/12/24 horas.
