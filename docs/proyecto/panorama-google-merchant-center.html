Cómo se actualiza Google

Google Merchant Center se conecta así:

Panel /admin → API route → Neon
Neon → /products.xml
/products.xml → Google Merchant Center

No se sube XML a Neon. Neon es la fuente; Next.js genera el feed cuando Google lo solicita.
